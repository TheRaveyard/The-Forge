# The-Forge

## Управление

- WASD / стрелки — движение относительно направления камеры.
- Пробел — прыжок.
- Удерживать ПКМ и двигать мышью — обзор. После отпускания ПКМ курсор освобождается.
- E — подобрать один предмет под курсором в пределах 3 единиц. При обзоре используется центр экрана.
- Q — бросить предмет в направлении курсора или центра экрана.

Руда Bronze/Copper/Gold и шесть префабов слитков настроены для физического подбора.
Для новых предметов нужны `PickupItem`, динамический `Rigidbody` и физический Collider.
Не включайте Static и Is Trigger. Для бросаемых предметов используйте Interpolate и Continuous Dynamic.

Статическая проверка ресурсов: `powershell -File Tools/Verify-InputSystem.ps1`.
Она проверяет ввод и подключения, но не заменяет проверку физики, камеры и звука в игровом режиме.
